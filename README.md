## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd qa_auto_tandoor
   ```

2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/Mac
   # или
   venv\Scripts\activate     # Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Настройте переменные окружения в `.env`:
   ```
   BASE_URL=https://app.tandoor.dev
   TANDOOR_TOKEN=your_token_here
   TANDOOR_USERNAME=your_username_here
   TANDOOR_PASSWORD=your_password_here
   ```

## Получение API-токена

1. Авторизуйтесь в Tandoor
2. Перейдите в раздел API в настройках
3. Создайте новый токен с правами "write"
4. Сохраните токен в `.env`

## Запуск тестов

### 🚀 Локальное тестирование с мок-сервером (рекомендуется)

Для тестирования без доступа к внешнему API Tandoor:

1. **Запустите мок-сервер** (в отдельном терминале):
   ```bash
   python mock_tandoor_server.py
   ```
   Сервер запустится на `http://localhost:8000`

2. **В новом терминале запустите тесты**:
   ```bash
   # Все UI-тесты с мок-сервером
   pytest tests/test_ui_local_mock.py -v
   
   # С открытым браузером (для визуальной отладки)
   pytest tests/test_ui_local_mock.py -v -s
   ```

3. **Тесты пройдены!** ✅
   - `test_login_local` - логин на локальном сервере
   - `test_create_meal_plan_local` - создание плана питания
   - `test_shopping_list_local` - проверка списка покупок

### Запуск всех тестов с реальным API
```bash
pytest
```

### Запуск API-тестов
```bash
pytest -m api
```

### Запуск UI-тестов
```bash
pytest -m ui
```

### Генерация Allure-отчета
```bash
pytest --alluredir=allure-results
allure serve allure-results
```

## CI/CD

Проект настроен для автоматического запуска тестов в GitLab CI с генерацией Allure-отчетов и публикацией на GitLab Pages.

- Page Object Model обеспечивает поддерживаемость UI-тестов
- Автоматическая генерация скриншотов при падении UI-тестов
